| Folder   | Purpose                                                    |
| -------- | ---------------------------------------------------------- |
| `lib/`   | Reusable modules and functions (library code)              |
| `bin/`   | Executable scripts (entry points for scheduler, CLI, etc.) |
| `utils/` | Helper functions, logging, common utilities                |
| `tests/` | Unit tests for modules                                     |
